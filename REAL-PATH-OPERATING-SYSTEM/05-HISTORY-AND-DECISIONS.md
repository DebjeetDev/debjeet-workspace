The first J3 version deliberately used:

- a factory function,
- one closure-returned dispatcher,
- a private array,
- callbacks,
- unsubscribe functions,
- simple conditions.

It deliberately avoided object literals, object methods, Map, Set, class, async code, UI, and object payloads. The reason was to keep the project before the Objects phase.
