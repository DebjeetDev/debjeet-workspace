PART 4 — KYA-KYA PAKDEGA (4 Leak Types)
==============================================================================

LEAK 1:  BHULI HUI SUBSCRIPTION
         Rule:  Ek merchant 3 ya zyada baar aaya
                AUR har baar price SAME (ya 5% ke andar)
                AUR gap lagbhag 25-35 din

         Example:  NETFLIX 199, 4 baar  ->  Rs 199/month
                   Saal ka: Rs 2,388


LEAK 2:  DUPLICATE CHARGE  (India mein BAHUT hota hai!)
         Rule:  Ek hi merchant
                Ek hi amount
                Ek hi din (ya 1 din ke andar)
                Do baar

         Example:  GYM CULT 1499, same day, 2 baar
                   -> Rs 1,499 ka nuksan!
         (UPI failed transaction ke baavjud debit ho jata hai - real problem)


LEAK 3:  CHAI-PANI LEAK  (chhote-chhote payments)
         Rule:  Rs 100 se kam ke transactions
         Phir:  Unka total + monthly average

         Example:  CHAI POINT 30 x 3 + aur chhote
                   -> Rs 4,200 saal ke
         (86% UPI payments Rs 500 se kam hain - yahi sabse bada leak hai)


LEAK 4:  KISI EK MERCHANT PAR BAHUT ZYADA
         Rule:  Ek merchant par total spend
                Rs 2,000 se upar ho

         Example:  ZOMATO Rs 550
         (aage chalkar limit badha sakte hain)

PART 5 — FUNCTION LIST (Jira Ticket Style — Koi Code Nahi)
==============================================================================

    HAR FUNCTION YE RULE FOLLOW KAREGA:
        - Guard clause pehle
        - Result Box return kare:  { status, ok, data }  ya  { status, ok, error }
        - Original array ko KABHI change na kare


    1.  getAmounts(rows)
        Kaam:   Sirf amounts ki list nikaalo
        Tool:   .map()
        Input:  statement
        Output: [199, 30, 240, 199, ...]


    2.  getTotalSpend(rows)
        Kaam:   Kul kitna kharcha hua
        Tool:   .reduce()
        Guard:  Khali array -> 0
        Output: Ek number


    3.  filterByMerchant(rows, merchantName)
        Kaam:   Sirf ek merchant ki rows
        Tool:   .filter()
        Guard:  Naam khali ho -> error
        Output: Rows ki chhoti list


    4.  findBigSpends(rows, limit)
        Kaam:   limit se bade transactions
        Tool:   .filter()
        Guard:  limit positive number hona chahiye


    5.  detectDuplicateCharges(rows)
        Kaam:   Same merchant + same amount + same/next din = pakdo
        Tool:   .filter()
        Output: Suspect rows + kitne rupaye doobe


    6.  detectSubscriptions(rows)
        Kaam:   3+ baar, same price = subscription
        Tool:   .filter() + count logic
        Output: Merchant, monthly cost, SAAL KA COST


    7.  calculateSmallLeak(rows, smallLimit)
        Kaam:   Chhote payments ka total
        Tool:   .filter() + .reduce()
        Output: Total + monthly average


    8.  buildReport(rows)
        Kaam:   Upar ke sabko mila kar EK report
        Output: Result Box jisme poora summary ho
