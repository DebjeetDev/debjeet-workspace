PART 3 — CONCEPT (TOOLBOX KA NAKSHATA)
----------------------------------------------------------------

  EK NAZAR MEIN POORA TOOLKIT:

  ┌────────────────┬──────────────┬────────────────────┬────────────────┐
  │ KAAM           │ TOOL         │ WAPAS DETA         │ ORIGINAL BADLA?│
  ├────────────────┼──────────────┼────────────────────┼────────────────┤
  │ Pehla match    │ find(fn)     │ item ya undefined  │ nahi           │
  │ Match ka ghar  │ findIndex(fn)│ number ya -1       │ nahi           │
  │ "Hai kya?"     │ includes(x)  │ true / false       │ nahi           │
  │ Ghar (purana)  │ indexOf(x)   │ number ya -1       │ nahi           │
  │ "Koi ek?"      │ some(fn)     │ boolean            │ nahi           │
  │ "Sab?"         │ every(fn)    │ boolean            │ nahi           │
  │ Tukda          │ slice(a, b)  │ NAYA array         │ NAHI (safe)    │
  │ Jodo           │ concat(arr)  │ NAYA array         │ nahi           │
  │ Order          │ sort(fn?)    │ WAHI array         │ ⚠️ HAAN        │
  │ Unique         │ new Set(arr) │ Set (spread karo)  │ nahi           │
  │ Kholna         │ [a,b] [h,..t]│ variables          │ nahi           │
  └────────────────┴──────────────┴────────────────────┴────────────────┘

  ⭐ ZINDAGI BHAR KA MANTRA ⭐

     Har tool use karne se pehle EK sawaal:
         "YE ORIGINAL BADALTA HAI?"

     BADALNE WALE (danger zone):
         push  pop  shift  unshift  splice  sort

     NAHI BADALNE WALE (safe zone):
         map  filter  reduce  find  findIndex
         slice  concat  spread  Set  includes  some  every

     RULE:
         Badalne wala mile -> PEHLE COPY:  [...arr]
         Phir jo karna hai kar. Basta. Khatam. 🔒

  CHHOTA FORM (90% kaam yahin se):

    // haan/na
    arr.includes(240)                  // true
    arr.some(a => a > 500)             // true
    arr.every(a => a < 5000)           // true

    // pehla match
    arr.find(a => a > 500)             // 2499 ya undefined
    arr.findIndex(a => a > 500)        // index ya -1

    // tukda + order (SAFE version)
    [...arr].sort((a, b) => b - a).slice(0, 3)   // top-3, original zinda

    // unique
    [...new Set(arr)]

PART 4 — CODE (MAINE NODE PE CHALAYA — ASLI OUTPUT)
----------------------------------------------------------------

  Tera data (poori file mein yahi):
      const amounts = [240, 45, 2499, 9, 240, 60];

  ---------------------------------------------------------
  EXAMPLE 1 — DHOONDHNA (find family)
  ---------------------------------------------------------
    amounts.find(a => a > 1000)      // -> 2499
    amounts.find(a => a > 5000)      // -> undefined   ⚠️
    amounts.findIndex(a => a === 9)  // -> 3
    amounts.includes(240)            // -> true
    amounts.indexOf(45)              // -> 1

  ANDAR ANDAR KYA HUA (find ka scan):
    line 1: 240  > 1000?  NAHI  -> aage
    line 2: 45   > 1000?  NAHI  -> aage
    line 3: 2499 > 1000?  HAAN  -> PAKDA. RUK GAYA.
    (line 4,5,6 DEKHI HI NAHI. Yehi taaqat hai.)

  ⭐ undefined ka matlab: "maine poora dekha, nahi mila."
     Crash NAHI hoga. Par agar tune bina pooche use kiya —
     PART 5 ka BUG B dekh. ☠️

  ---------------------------------------------------------
  EXAMPLE 2 — SAWAL (some / every)
  ---------------------------------------------------------
    amounts.some(a => a > 2000)      // -> true     (2499 — ek kaafi)
    amounts.every(a => a < 5000)     // -> true     (sab maante hain)
    amounts.every(a => a < 100)      // -> false    (gaddar mila)

  ANDAR ANDAR (every ka gussa):
    every line 3 pe hi ruk gaya — 2499 ne gaddari ki.
    every ko SAB chahiye, isliye EK false = poora false.

  ---------------------------------------------------------
  EXAMPLE 3 — TUKDA (slice — safe hai)
  ---------------------------------------------------------
    amounts.slice(1, 4)   // -> [45, 2499, 9]
    amounts.length        // -> 6          ✅ ORIGINAL ZINDA

  NOTE: slice(start, end) — start SE, end tak (end KHUD NAHI).
        Photocopy nikali, register jaisa ka taisa.

  ---------------------------------------------------------
  EXAMPLE 4 — ORDER (sort — DRAMA yahin)
  ---------------------------------------------------------
    [10, 9, 80, 100].sort()                 // -> [10, 100, 80, 9]  ❌
    [10, 9, 80, 100].sort((a, b) => a - b)  // -> [9, 10, 80, 100]  ✅
    [10, 9, 80, 100].sort((a, b) => b - a)  // -> [100, 80, 10, 9]  ✅

    const orig = [240, 45, 2499];
    const sorted = [...orig].sort((a, b) => b - a);
    sorted   // -> [2499, 240, 45]
    orig[0]  // -> 240        ✅ ASLI ZINDA (copy pe kaam hua)

  COMPARATOR KA MATLAB (ek line):
      (a, b) => a - b    -> chhota pehle   (ascending)
      (a, b) => b - a    -> bada pehle     (descending)
      Bas. Aur kuch nahi. Ye 2 line RAT LE. 🔒

  ---------------------------------------------------------
  EXAMPLE 5 — UNIQUE (Set)
  ---------------------------------------------------------
    [...new Set(amounts)]   // -> [240, 45, 2499, 9, 60]

  ANDAR ANDAR:
    Set = shaadi list. 240 pehli baar aaya -> andar.
    240 DOBARA aaya -> "baith gaya hai pehle se" -> bahar.
    Spread [...] us Set ko wapas NORMAL array banata.

  ---------------------------------------------------------
  EXAMPLE 6 — KHOLNA (array destructuring)
  ---------------------------------------------------------
    const [first, second] = amounts;
    // first -> 240, second -> 45

    const [head, ...tail] = amounts;
    // head -> 240
    // tail -> [45, 2499, 9, 240, 60]

    const [a, , c] = [10, 20, 30];
    // a -> 10, c -> 30      (beech wala SKIP — khaali jagah)

    let x = 1, y = 2;
    [x, y] = [y, x];
    // x -> 2, y -> 1        (SWAP — temp variable GAYAB)

  ---------------------------------------------------------
  EXAMPLE 7 — SAB MILA KAR (yehi company code hai)
  ---------------------------------------------------------
    // "Top-3 bade kharche" — SAFE tareeke se:
    const top3 = [...amounts]
      .sort((a, b) => b - a)     // copy pe order
      .slice(0, 3);              // pehle 3
    // -> [2499, 240, 240]
    // amounts abhi bhi: [240, 45, 2499, 9, 240, 60]  ✅

  YAHA CHAINING BHI HO GAYI — copy -> sort -> slice.
  Har kaam ek line, har line ka data agle mein.
  Yehi "assembly line" hai. Tu ye already reduce mein karta tha.

PART 5 — ⚠️ DO KHATARNAAK BUG (har ek 3 ghante khata hai)
----------------------------------------------------------------

  ---------------------------------------------------------
  BUG A — SORT KA DOUBLE DHOKA
  ---------------------------------------------------------

  DHOKHA 1 (STRING TRAP):
    Bina comparator ke sort har number ko pehle STRING
    banata hai, phir DICTIONARY ki tarah compare karta hai.

    Dictionary dekho:
        "10"  vs  "9"
        pehla akshar:  '1'  vs  '9'
        '1' pehle aata hai -> "10" JEET GAYA. 9 haar gaya.

    Isliye:
        [10, 9, 80, 100].sort()  ->  [10, 100, 80, 9]

    Computer PAGAL NAHI HAI.
    Rule kitaab mein likha hai — TUNE BATAYA NAHI. 😄

  DHOKHA 2 (MUTATION TRAP):
      const amounts = [240, 45, 2499];
      const s = amounts.sort((a, b) => b - a);
      amounts[0];    // -> 2499   💥 ASLI LIST BIGAD GAYI

    sort koi naya array NAHI deta.
    Wo WAHI purani list ko ulat-phoolt kar deta hai.
    Aur tu sochta rahega "meri list to safe thi".

  EK LINE FIX (donon dhokhon ka ilaaj):
      const s = [...amounts].sort((a, b) => b - a);
      //        ^^ copy   ^^ comparator
      // Dono BINA -> bina insurance ke gaadi. 🔒

  ---------------------------------------------------------
  BUG B — FIND KE BAAD KA KHAMOSH QAATIL
  ---------------------------------------------------------

      const mila = amounts.find(a => a > 5000);   // -> undefined
      console.log(mila * 2);                       // -> NaN   💀

    Crash nahi. Error nahi. Stack trace nahi.
    Bas NaN paida hua — aur aage chalta raha,
    har total kharab karta gaya, KISI KO PATA NAHI.

    YE SABSE BURA BUG HAI: JO AWAAZ NAHI KARTA.

  FIX (tera guard-clause wala dimaag se):
      const mila = amounts.find(a => a > 5000);
      if (mila === undefined) {
        return { status: 404, ok: false, error: "not found" };
      }

  ⭐ EK LINE MEIN:
     find HAMESHA undefined de sakta hai.
     PEHLE POOCHHO, PHIR USE KARO. 🔒

     (findIndex ka -1 bhi yahi bhai-behen hai —
      mila ya nahi, check karke hi aage badho.)

PART 6 — JUNIOR ❌ vs SENIOR ✅
----------------------------------------------------------------

  SITUATION: Boss bola — "UPI rows se top-3 sabse bade
             spends chahiye, kal subah report mein."
             rows = [date, shop, amount]

  ----------------------------------------------------------------
  ❌ JUNIOR KA CODE
  ----------------------------------------------------------------
    function top3(rows) {
      rows.sort((a, b) => b[2] - a[2]);
      return rows.slice(0, 3);
    }

    KYA GALTI HAI:
      1. rows.sort() — ORIGINAL list bigaad di  💥
         (baaki program purane order pe tha — ab sab ulta)
      2. rows null/undefined aaya -> seedha CRASH
      3. row ke andar garbage hua -> sort pagal
      4. Naam top3 — kal ko boss bole top-10 -> dobara likhna
      5. Guard zero. Sirf "chal gaya" jhooth.

  ----------------------------------------------------------------
  ✅ SENIOR ENGINEERING MANAGER KA CODE
  ----------------------------------------------------------------
    /**
     * UPI rows se top-n spends nikaalta hai.
     * Original array touch NAHI hota.
     * @param {Array<Array>} rows  [date, shop, amount]
     * @param {number} n
     */
    function topSpends(rows, n = 3) {
      // Guard 1 — array hi hai?
      if (!Array.isArray(rows)) {
        return { status: 400, ok: false, error: "rows must be an array!" };
      }

      const data = [...rows]                          // ⭐ copy PEHLE
        .filter(r => Array.isArray(r) && Number.isFinite(r[2]))
        .sort((a, b) => b[2] - a[2])                  // ⭐ comparator PAKKA
        .slice(0, n);                                 // ⭐ tukda AAKHIR mein

      return { status: 200, ok: true, data };
    }

    KYA SEEKHNE JAISE HAI:
      ✅ Guard clauses SABSE PEHLE
      ✅ [...rows] copy — asli data jaisa ka taisa
      ✅ filter se garbage bahar (tera purana jaan Number.isFinite)
      ✅ comparator HAMESHA — string trap ka koi chance nahi
      ✅ default parameter n = 3 — kal ko top-10 BHI chalega
      ✅ Consistent return: { status, ok, data | error }

    FARK:
      Junior  : "chal gaya, chhod"
      Senior  : "chal gaya... par tootega kahan?"

      (maine abhi GitHub se source fetch karke verify kiya ✅)

  ASLI CODE (bilkul waisa ka waisa):

    // off() — ek handler HATANA:
    handlers.splice(handlers.indexOf(handler) >>> 0, 1);

    // emit() — sabko event DENA:
    handlers.slice().map((handler) => {
      handler(evt);
    });

  LINE BY LINE, AAM AADMI KI BHASHA MEIN:

  LINE 1:  handlers.indexOf(handler)
     "Is list mein ye handler Kitne number ghar mein hai?"
     indexOf ghar-number DHOONDTA hai.
     -> aaj ka tool, duniya ke asli code mein. ✅

     (>>> 0 ek chhota unsigned trick hai — is depth mein
      abhi mat jaa. Bas itna yaad rakh: indexOf -1 bhi de
      sakta hai, aur mitt ne uska khayal rakha hai.)

  LINE 2:  handlers.splice(ghar, 1)
     "Us ghar se EK member nikaal do."
     splice = hatana — aur ye MUTATING hai.
     Par mitt ke andar CONTROLLED jagah pe use hota hai.
     Mutation bura nahi — BINA SOCHA mutation bura hai.

  LINE 3 (⭐ SONE KI LINE):  handlers.slice().map(...)
     Pehle .slice() = PHOTOCOPY.
     Phir .map() = photocopy pe sabko bula.

     COPY KYUN?
       Soch: ek handler chalte-chalte KHUD ko off() karde
       (khud ko list se hata le).
       Agar hum ORIGINAL list pe chal rahe hote —
       list beech mein badli -> agla handler skip/bhabhak -> 💥

       Isliye mitt ORIGINAL ko haath lagaye bina,
       PHOTOCOPY pe poora round chalata hai.

  ⭐ YE HAI "TOOTEGA KAHAN?" WALI SOCH.
     Duniya ke best engineers SAME .slice() karte hain
     jo aaj PART 4 mein tune seekha.

     Junior ❌ : list pe seedha loop, beech mein badal gayi to crash
     Senior ✅ : pehle copy, phir kaam

  TUJHE KYA CHEEN KE RAKHNA CHAHIYE:
    1. indexOf / slice sirf syllabus NAHI — production me jeete hain
    2. Copy-pehle ka mantra kisi bade library mein bhi same
    3. Mutation = hathiyar. Controlled jagah pe theek,
       laparwahi se MOUT.
