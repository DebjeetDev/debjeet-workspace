PART 2 — EK IMANDAAR BAAT (Main Ye Kyun Nahi Kar Sakta)
==============================================================================

    Tu chahta hai ki MAIN tera GitHub par push karoon.

    Lekin main ye nahi kar sakta. Do wajah:

    1.  Mere paas tera GitHub password ya token NAHI hai.
        ( Aur hona bhi nahi chahiye. )

    2.  Sabse zaroori:  TU MUJHE APNA TOKEN DEGA, YE GALAT HOGA.

        Ek asli engineer KABHI apna access token kisi ke saath
        share nahi karta — chahe wo mentor ho, dost ho, ya company.

        Agar token leak ho gaya, toh koi bhi tere saare repos
        delete kar sakta hai.

        Ye main tujhe SIKHA raha hoon, isliye mana kar raha hoon.

    ISLIYE SOLUTION YE HAI:
        Main sab kuch TAIYAAR kar doonga.
        Tu EK COMMAND chalayega.
        10 second ka kaam.

PART 4 — sync.sh KYA KARTA HAI
==============================================================================

    ./sync.sh

    1.  Saare files stage karta hai        (git add -A)
    2.  Commit karta hai timestamp ke saath
    3.  GitHub par push karta hai

    Aur agar kuch galti ho:
        - Remote set nahi  ->  tujhe bata dega kya karna hai
        - Koi badlav nahi  ->  bolega "sab pehle se saved hai"
        - Pehli baar       ->  khud repo bana dega

PART 6 — DOOSRA BACKUP (Agar GitHub Limit Kabhi Aa Jaye)
==============================================================================

    Spoiler: Tujhe ye KABHI nahi chahiye hoga.
    (1.5 MB vs 1 GB — limit door ki baat hai)

    Lekin phir bhi, ye options hain (research ke baad):


    OPTION A — GITLAB  ⭐ SABSE BEST
        Free tier:  10 GiB per project
                    (GitHub ke 1 GB se 10 GUNA ZYADA)
        Link:       https://gitlab.com
        Kyun best:  Sabse zyada jagah, free

        Setup:
            Naya repo banao GitLab par
            git remote add gitlab https://gitlab.com/USER/debjeet-workspace.git
            git push gitlab main


    OPTION B — CODEBERG
        Free tier:  750 MiB Git storage
                    100 repos
        Link:       https://codeberg.org
        Note:       GitHub se KAM jagah hai (750 MB)
                    Lekin non-profit hai, privacy achhi hai


    OPTION C — GITHUB + GIT LFS
        Free:       1 GB storage + 1 GB/month bandwidth
        Note:       Bandwidth ACCOUNT-WIDE hoti hai (per repo nahi)
                    Public repo mein log download karenge toh
                    TERI bandwidth khatam ho jayegi
        Isliye:     Ye option ACHHA NAHI HAI beginners ke liye


    MERI SALAH:
        Primary:   GitHub  (roz ka backup)
        Secondary: GitLab  (mahine mein ek baar mirror)
        Isse zyada ki zaroorat hi nahi.

PART 8 — JO CHEEZEIN BACKUP NAHI HONGI
==============================================================================

    .gitignore mein ye rok diya hai:

        .npm/          npm ka cache
        node_modules/  dependencies
        __pycache__/   Python cache
        .DS_Store      Mac junk
        .vscode/       editor settings
        .env           SECRETS (kabhi mat bhejna!)
        *.token        SECRETS
        id_rsa         SSH keys (kabhi mat bhejna!)

    AUR YAAD RAKH:
        .env, token, SSH key  ->  YE KABHI BHI GITHUB PAR NAHI.
        Agar galti se chala gaya, toh wo LEAK ho gaya.
        (Isliye .gitignore mein pehle se rok diya hai)
