PART 5 — DATA KA STRUCTURE (Kya kya milega)
==============================================================================

    channels.json  — HAR CHANNEL MEIN YE FIELDS:

        id            Unique ID (jaise "ABPAnanda.in")
        name          Channel ka naam (jaise "ABP Ananda")
        alt_names     Doosre naam
        network       Network
        owners        Malik kaun hai
        country       Desh code ("IN", "US")
        categories    ["news"], ["sports"], ["movies"]...
        is_nsfw       Adult content hai ya nahi (true/false)
        launched      Kab shuru hua
        closed        Kab band hua (null = abhi zinda)
        replaced_by   Iski jagah kaunsa channel aaya
        website       Official site


    streams.json  — HAR STREAM MEIN YE FIELDS:

        channel       Channel ID (jaise "ABPAnanda.in")
        feed          Feed ID (ho bhi sakta hai, nahi bhi)
        title         Stream ka title
        url           *** ASLI .m3u8 LINK ***  <- SABSE ZAROORI
        referrer      Kuch streams ko Referer header chahiye
        user_agent    Kuch streams ko User-Agent chahiye
        quality       "1080p", "720p", "480p"...
        labels        ["Geo-blocked"], ["Not 24/7"]


    SAMPLE (asli data):
        https://stream.ottlive.co.in/4sidestv/index.m3u8
        https://cdn.pishow.tv/ott/live/1007/master.m3u8

PART 6 — TU ISE ABHI KAISE USE KAREGA (Phase 5 skills se)
==============================================================================

    ABHI TU YE KAR SAKTA HAI (sirf arrays se):

        Data ko array-of-arrays ki tarah soch:
            ["ABPAnanda.in", "ABP Ananda", "IN", "news", false]

        .filter() se:
            - Sirf India ke channels        (country === "IN")
            - Sirf non-NSFW                 (is_nsfw === false)
            - Sirf jo band nahi hue         (closed === null)
            - Sirf 720p ya usse upar

        .map() se:
            - Har channel ka display naam banana

        .reduce() se:
            - Total count ginna
            - Kitne HD hain, kitne nahi

    PHASE 6 (Objects) ke baad:
        - Channel + Stream ko MERGE karna
          (channel ID se streams.json mein dhoondhna)

    PHASE 7 (Async) ke baad:
        - fetch() se live data mangwana
        - HLS.js se video chalana
