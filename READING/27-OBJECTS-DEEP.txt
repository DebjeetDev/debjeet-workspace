PART 1 — OBJECT KYA HAI (sirf 3 niyam, bas!)
----------------------------------------------------------------

  OBJECT = naam wali THAALI.
  Har katori pe LABEL likha hai: key → value.

    const chavi = {
      key1: value1,      // LABEL : CHEEZ
      key2: value2
    };

  NIYAM 1: key hamesha NAAM hota hai (string jaisa).
           date, shop, amount — koi bhi.
  NIYAM 2: ek thaali mein EK naam EK hi baar.
           do baar likha to pichhla khada hua naya kha jayega.
  NIYAM 3: THAALI ke andar KUCH BHI rakh sakta hai:
           text, number, true/false, ARRAY, aur OBJECT bhi! 😈

  TRY DRIYA (kagaz pe soch, code baad mein):
    const fan = { brand: "Havells", speed: 350, on: false };
    fan.on     -> ???
    fan.speed  -> ???
    fan.brand -> ???
  (Answers: false / 350 / "Havells")

PART 2 — ACCESS KE 2 RAASTE: dot .  aur  bracket [ ]
----------------------------------------------------------------

  DAAST 1 — DOT (jhatt, aam taur pe yahi):
      spend.amount   ->  30
      spend.shop     ->  "Chai Shop"
      spend.deta     ->  undefined  ⚠️ (typo! error nahi aaya —
                                       khamosh galat jawab ye
                                       object ka pehla jhooth hai)

  RAAST 2 — BRACKET (jab naam VARIABLE mein ho):
      const kya = "amount";
      spend[kya]     ->  30         ✅ variable se kaam!
      spend.kya      ->  undefined  ❌ (usne "kya" naam dhoonda!)
      spend["amount"] -> 30         (seedha string bhi chalega)

  ⭐ YAAD RAKHNE KA MANTRA:
      "KEY fix ho to DOT.  KEY dabbe mein ho to BRACKET."

  TV project mein BRAACKET har roz kaam aayega:
      streamMap[channel.id]   ⬅ channel.id ek VARIABLE hai! 🎯

PART 5 — OBJECT DESTRUCTURE: ST5 KA BARHA BHAI 📦
----------------------------------------------------------------

 readonly yaad hai?
    const [head, ...tail] = list;          // ARRAY wala (ST5)

 OBJECT wala iska bhai — par ye NAAM se kholta hai:

    const { shop, amount } = spend;
    shop    -> "Chai Shop"
    amount  -> 30

  POSITION ka koi matlab NAHI — sirf NAAM ka:

    const { amount, shop } = spend;        // ulta likha? FARK NAHI ✅

  2 AUR CHAKKU (kagaz pe):
    const { shop: dukaan } = spend;        // naam BADAL ke nikala
    dukaan  -> "Chai Shop"
    const { tax = 0 } = spend;             // nahi hai to DEFAULT
    tax     -> 0

  ⭐ FUNCTION ke ANDAR seedha kholna (asli duniya mein yahi hota hai):
    function printLine({ shop, amount }) {
      return shop + " pe " + amount + " kharch";
    }
    printLine(spend)   ->  "Chai Shop pe 30 kharch"

PART 6 — SPREAD {...} — COPY BANA KE BADLO ⭐⭐
----------------------------------------------------------------

  Pachwaa ka gyaan yaad hai? sort() ka jhaansa:
      const copy = [...rows];   // array ki ante-grade COPY, phir sort

  OBJECT ka version:

      const nayaSpend = { ...spend, amount: 25 };

  MATLAB: poori thaali UTAAR do NAYI thaali mein,
          aur amount wali katori UPAR se dobara bharti do.

  ASLI JAADU — original ZINDA rehta hai:
      nayaSpend.amount  -> 25   ✅ naya badla
      spend.amount      -> 30   ✅ purana untouched (immutability!)

  ⭐ VARIABLE KEY ke saath (yehi ST2 mein kaam aayega):
      const key = "amount";
      const updated = { ...spend, [key]: 25 };
      // [key] ka matlab: dabbe ke andar jo naam hai, WO label banao

  KYUN YE RULE #1 HAI? Kyunki real apps (React aage chal ke)
  PURANE data ko haath nahi lagane dete. Nayi copy banao.
  Ye soch = immer library ka dil (PART 9 mein uska link).

📖 KHUD PADHO (5 min): MDN — Spread syntax (objects wala hissa)
   https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax

PART 7 — Object.keys / values / entries (object pe bhi loop!)
----------------------------------------------------------------

  Array pe tu map/filter laga leta hai...
  OBJECT pe seedha nahi chalta. To object ko PEHLE array banao:

    Object.keys(spend)     -> ["date", "shop", "amount"]   (labels!)
    Object.values(spend)   -> ["06 Oct", "Chai Shop", 30]  (cheezein)
    Object.entries(spend)  -> [ ["date","06 Oct"],
                                ["shop","Chai Shop"],
                                ["amount",30] ]            (jodi-jodi!)

  MANTRA: "Pehle entries nikaal, phir PHASE 5B ke saare
           hathiyar laga de." (map/filter — sab chal jayega!)

  Mini-try (kagaz pe):
    Object.keys({name:"ABP", country:"IN", url:"x"})   -> ??? 
    (Answer: ["name","country","url"])

📖 KHUD PADHO (3 min): MDN — Object.entries()
   https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/entries

PART 8 — JSON: DUNIYA SE BAAT KARNE KA TARIKA 🌍
----------------------------------------------------------------

  Sawaal: object MEMORY mein to rehta hai...
  use FILE mein kaise rakho? INTERNET pe kaise bhejo?
  (localStorage tera Future PIN-vault! server se aane wala data!)

  JAWAB: JSON — object ko TEXT mein badal do.

    const text = JSON.stringify(spend);
    //  '{"date":"06 Oct","shop":"Chai Shop","amount":30}'   (ek string!)

    const wapas = JSON.parse(text);
    //  { date: "06 Oct", shop: "Chai Shop", amount: 30 }   (object wapas!)

  ROUNDTRIP mantra:  bhejna ho  -> stringify
                     lena  ho  -> parse

  2 RULES (likh lo):
    1. JSON mein sirf DATA — function nahi chalega, undefined
       nahi chalega. Naam double-quote mein ("shop" — ye JSON ka
       style hai, JS se thoda sakht).
    2. parse GADBAD text pe CRASH karta hai — isliye Phase 7 mein
       hum ise try/catch ki suraksha mein bharenge.

PART 11 — STAGES (yahi file ka tracker hai) 📋
----------------------------------------------------------------

  Har stage: pehle KAGAZ pe, phir code, phir expected match.
  Guard wahi ghar ka style: fail → { status:400, ok:false }

  ------------------------------------------------------------
  STAGE 1 — ROW SE THAALI (15 min)
  ------------------------------------------------------------
    F. rowToObject(row)
       -> ["06 Oct","Chai Shop",30] mila to:
          { date:"06 Oct", shop:"Chai Shop", amount:30 }
       -> galat input (na-array ya 3 se kam) to 400-envelope.

    EXPECTED:
      rowToObject(["06 Oct","Chai Shop",30])
        -> { date:"06 Oct", shop:"Chai Shop", amount:30 }
      rowToObject("hi")           -> { status:400, ok:false }
      rowToObject(["06 Oct"])     -> { status:400, ok:false }

  ------------------------------------------------------------
  STAGE 2 — UPDATE-PRO (immutability proof!) (20 min)
  ------------------------------------------------------------
    G. updateSpend(spend, key, value)
       -> NAYA object de ({...spend, [key]:value} — PART 6!)
       -> PURANA spend BILKUL na badle.

    EXPECTED:
      const s  = rowToObject(["06 Oct","Chai Shop",30]).data;  
      const s2 = updateSpend(s, "amount", 25);
      s2.amount -> 25   ✅
      s.amount  -> 30   ✅ (SABOOT: original zinda!)
      updateSpend(s, "note", "office").note -> "office"  (nayi key ADD!)

  ------------------------------------------------------------
  STAGE 3 — DESTRUCTURE SE AWAAZ (15 min)
  ------------------------------------------------------------
    H. printSpend({ shop, amount })
       -> "Chai Shop pe 30 kharch"  jo string banaye
          (seedha destructure function ke darwaze pe!)

    EXPECTED:
      printSpend({ date:"06 Oct", shop:"Chai Shop", amount:30 })
        -> "Chai Shop pe 30 kharch"

    PAPER PE BHI (code NAHI):

        { shop:"Zomato", amount:240 };
      shop -> ???   amount -> ???   tax -> ???
      (Answer PART 12 ke neeche)

  ------------------------------------------------------------
  STAGE 4 — OBJECT PE TOOLKIT (20 min) ⭐
  ------------------------------------------------------------
    I. listKeys(obj)   -> Object.keys(obj) ki list de
       (guard + envelope — purana niyam!)

    J. ⭐ countByShop(spendObjects)
       input : spend objects ka ARRAY
       output: object — dukaan : kitni baar
       HINT: reduce (Phase 5 wala!) + bracket key [shop]
             aur "naya count = purana ya 0 + 1" soch 
             (acc[s.shop] hai? +1 : nahi? 1 se shuru)

    EXPECTED:
      countByShop ([{shop:"Chai",amount:30},{shop:"Zomato",amount:240},
                    {shop:"Chai",amount:25}])
        -> { Chai: 2, Zomato: 1 }

  ------------------------------------------------------------
  STAGE 5 — ⭐⭐⭐ THE MERGER (TV KA PILA PATRA!) (25 min)
  ------------------------------------------------------------
    K. mergeChannelStream(channel, streamMap)
       input 1: channel = { id:"abp", name:"ABP Ananda", country:"IN" }
       input 2: streamMap = { abp:"https://x.m3u8", zee:"https://y.m3u8" }
       kaam: NAYA object banao = channel ki saari cheezein
             + url: streamMap ka matching link
       na mile link -> { status:404, ok:false, error:"no stream for id" }
       guard: channel object hi hai? streamMap object hi hai?

    EXPECTED:
      mergeChannelStream(
        { id:"abp", name:"ABP Ananda", country:"IN" },
        { abp:"https://x.m3u8", zee:"https://y.m3u8" })
        -> { id:"abp", name:"ABP Ananda", country:"IN",
             url:"https://x.m3u8" }

      mergeChannelStream({ id:"sony", name:"Sony" }, { abp:"..." })
        -> { status:404, ok:false, error:"no stream for id" }

    HINT: url nikalne ka raasta = streamMap[channel.id]
          (PART 2 ka bracket — KYAA variable hai! 🎯)
          aur spread {...channel, url: ...} (PART 6!)
