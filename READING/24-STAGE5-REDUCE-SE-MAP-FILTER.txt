PART 2 — EK HI RAAG, DO GEET
----------------------------------------------------------------

  DONO KA STRUCTURE EK Jaisa HAI:

    array.reduce((acc, cur) => {
      // kuch karo
      return acc;
    }, []);              // ⭐ INITIAL = KHALI ARRAY

  FARK SIRF "KUCH KARO" MEIN:

    map     ->  acc.push( BADLA HUA cur )
    filter  ->  if (condition) acc.push( WAISA HI cur )

  AUR EK ZAROORI BAAT:
    DONO MEIN  return acc;  HONA HI CHAHIYE.
    Bhule -> agle round mein acc = undefined -> CRASH.
    (Ye bug tu pehle hi dekh chuka hai — PART 8 / Bug 2)

PART 3 — mapWithReduce
----------------------------------------------------------------

  KYA KARNA HAI:
    Har item ko BADAL kar nayi array mein daalna.

  EXAMPLE:
    mapWithReduce([1,2,3], n => n * 2)   ->  [2,4,6]

  KHOKHA:

    function mapWithReduce(numbers, fn) {
      // Guard 1
      if (!Array.isArray(numbers)) {
        return { status: 400, ok: false, error: "Input must be a valid array!" };
      }
      // Guard 2
      if (typeof fn !== "function") {
        return { status: 400, ok: false, error: "Second argument must be a function!" };
      }

      const result = numbers.reduce((acc, cur) => {
        acc.push(______);        // ← BLANK 1
        return acc;
      }, ______);                // ← BLANK 2

      return { status: 200, ok: true, data: result };
    }

  BLANK 2 AASAN HAI:  []
    (kyunki hum ARRAY bana rahe hain)

  BLANK 1 SOCH:
    map ka kaam kya hai? Har item ko BADALNA.
    Badalne wala kaun hai?  fn
    Toh...  fn(cur)

  JAWAB:
    acc.push(fn(cur));
    return acc;
    }, []);

PART 4 — filterWithReduce
----------------------------------------------------------------

  KYA KARNA HAI:
    Sirf wahi items rakhna jo condition pass karein.
    Item ko BADALNA NAHI HAI.

  EXAMPLE:
    filterWithReduce([1,2,3,4], n => n > 2)   ->  [3,4]

  KHOKHA:

    function filterWithReduce(numbers, fn) {
      if (!Array.isArray(numbers)) {
        return { status: 400, ok: false, error: "Input must be a valid array!" };
      }
      if (typeof fn !== "function") {
        return { status: 400, ok: false, error: "Second argument must be a function!" };
      }

      const result = numbers.reduce((acc, cur) => {
        if (______) {          // ← BLANK 1
          acc.push(______);    // ← BLANK 2
        }
        return acc;            // ⭐ HAMESHA
      }, ______);              // ← BLANK 3

      return { status: 200, ok: true, data: result };
    }

  BLANK 3:  []   (phir se array)
  BLANK 1:  fn(cur)   (condition check)
  BLANK 2:  cur       (WAISA HI, badla nahi)

  JAWAB:
    if (fn(cur)) {
      acc.push(cur);
    }
    return acc;
    }, []);

----------------------------------------------------------------
PART 5 — DONO MEIN EK LINE KA FARK
----------------------------------------------------------------

    map     :  acc.push( fn(cur) );        // BADLA HUA
    filter  :  if (fn(cur)) acc.push(cur); // WAISA HI

    map     :  HAR item jata hai
    filter  :  SIRF pass wale jate hain

    map     :  length SAME rahegi
    filter  :  length KAM ho sakti hai

  YAAD RAKH:
    map     ->  "badal ke daal"
    filter  ->  "chhaan ke daal"

  AUR SABSE ZAROORI (DONO MEIN):
    return acc;   ⭐
