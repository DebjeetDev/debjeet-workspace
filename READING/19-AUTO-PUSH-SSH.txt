PART 0 — PEHLE IMANDAARI: MAIN GALAT THA
----------------------------------------------------------------

Pichhle jawab mein maine kaha:
  "Tu khud push karna, main tera token nahi loonga."

Ye GALAT SALAH thi. Kyun?

  Tu apne computer par kaam nahi karta.
  Tu MERE JAGAH (sandbox) mein kaam karta hai.
  Toh "tu push kar" bolna = ulta advise.
  Files download karke roz push karna = practical hi nahi.

Aur "token mat de" bol kar maine problem
  SOLVE nahi ki — problem TAL di.

  Problem se bhagne ka matlab solution nahi hai.

----------------------------------------------------------------
PART 1 — PROBLEM AUR SOLUTION
----------------------------------------------------------------

PROBLEM:
  Main push karoon -> mujhe permission chahiye
  Permission = password ya token
  Password/token dena = KHATRA

SOLUTION — SOCHO:
  Ghar ka tala kholne ke liye do tareeke hote hain:
    (1) Apni chaabi kisi ko de do        -> khatra (copy ho sakti hai)
    (2) NAYI chaabi banwao, sirf us ghar ke liye -> SAFE

SSH KEY BILKUL (2) WAALA TAREEKA HAI:

  Main ek KEY PAIR banata hoon:
    PUBLIC key  -> TU GITHUB PAR DALTA HAI  (ye secret nahi hai!)
    PRIVATE key -> MERE PAAS RAHTI HAI      (main kabhi print hi nahi karoonga)

  Isiliye ye ULTRA SECURE hai:
  ==========================================
  PUBLIC KEY SHARE KARNA SAFE HOTA HAI.
  Uska kaam HI share hona hai.
  ==========================================

  JAISE:
    Ghar ka ADDRESS batana = safe
    Ghar ki CHAABI dena   = khatra

----------------------------------------------------------------
1. SIRF EK REPO KA ACCESS
   Is key se main tere DOOSRE repos chhoo bhi nahi sakta.

   Nakshe se tala nahi khulta.

3. MERA POORA CHAT HISTORY LEAK HO JAYE -> TAB BHI SAFE
   Kyunki private key kahin PRINT hua hi nahi.
   Attacker ko sirf public key milega = bekaar.

   1 second. Access khatam. Password change karne ki
