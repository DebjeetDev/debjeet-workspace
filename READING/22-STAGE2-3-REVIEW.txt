PART 1 — 🐛 THE BUG: getBiggestSpend
----------------------------------------------------------------

  TERA CODE:
    const biggest = raws.reduce((acc, cur) => (cur > acc ? cur : acc), 0)

  OUTPUT:  0
  HONA CHAHIYE:  2499

------------------------------------------------------------------
KYUN? (YE SABSE ZAROORI PART HAI)
------------------------------------------------------------------

  TERA DATA YAAD HAI?

    const upi = [
      ["05 Oct", "Zomato", 240],     <- YE EK "ROW" HAI
      ["05 Oct", "Netflix", 499],
      ...
    ];

  reduce jab chalta hai, `cur` mein KYA AATA HAI?

    cur  =  ["05 Oct", "Zomato", 240]      <- POORA ARRAY
    cur[2] =  240                          <- ASLI AMOUNT

  TU NE LIKHA:     cur > acc
  HONA CHAHIYE:    cur[2] > acc

  MATLAB: TU POORE DABBE KO NUMBER SE COMPARE KAR RAHA THA!

  SOCH:
    Ek taraju hai.
    Ek taraf TERA KHAATA (0).
    Doosri taraf POORI KITAB ["05 Oct","Zomato",240].
    Taraju: "Kitab bhaari hai ya 0?"
    -> Jawab hi nahi ban sakta.

  TUJHE POOCHHNA CHAHIYE THA:
    "Kitab ke PAGE 2 pe jo NUMBER likha hai (240),
     wo 0 se bada hai?"

------------------------------------------------------------------
ANDAR JAAN HILA DENE WALI SACHCHAI
------------------------------------------------------------------

  JS mein ye ho raha hai:

    ["05 Oct", "Zomato", 240] > 0

  STEP 1:  Array ko string banao
           ["05 Oct","Zomato",240].toString()
           = "05 Oct,Zomato,240"

  STEP 2:  String ko number se compare karo
           Number("05 Oct,Zomato,240")  =  NaN

  STEP 3:  NaN > 0  =  FALSE

  ISLIYE HAR BAAR FALSE -> acc KABHI NAHI BADLA -> ANSWER 0

  AUR EK KAMAAL KI BAAT (ye yaad rakh):

    [240] > 0                      -> TRUE   ✅
    ["05 Oct","Zomato",240] > 0    -> FALSE  ❌

  KYUN?
    [240].toString() = "240"  -> Number("240") = 240 -> 240 > 0 = TRUE

  MATLAB: SIRF EK NUMBER HO TO JS SAMJH JATA HAI,
          MIX HO TO NAN HO JATA HAI.
          YE JS KI SABSE BADI KAMZORI HAI.

------------------------------------------------------------------
THE FIX (ek line)
------------------------------------------------------------------

  ❌  (cur > acc ? cur : acc)
  ✅  (cur[2] > acc ? cur[2] : acc)

  POORA:
    const biggest = raws.reduce(
      (acc, cur) => (cur[2] > acc ? cur[2] : acc),
      0
    );

  AB CHALEGA:
    baar 1: acc=0,    cur[2]=240   -> 240
    baar 2: acc=240,  cur[2]=499   -> 499
    baar 3: acc=499,  cur[2]=180   -> 499
    baar 4: acc=499,  cur[2]=30    -> 499
    baar 5: acc=499,  cur[2]=2499  -> 2499   ⭐
    baar 6: acc=2499, cur[2]=25    -> 2499
    RESULT: 2499  ✅

  ⭐ PEHLE KHUD LIKHNE KI KOSHISH KAR, PHIR UPAR SE MATCH KAR ⭐
