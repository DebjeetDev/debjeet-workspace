PART 6 — TROUBLESHOOTING
================================================================

"Key is already in use"
  -> Purani key doosre repo mein nahi chalegi
  -> NAYI key use karo (PART 2 / STEP 2 waali) ✅

"repository does not exist"
  -> Deploy key add nahi hui, ya "Allow write access"
     tick nahi kiya
  -> check: ssh -T git@github.com

"403 Forbidden — you must verify your email"
  -> npm email confirm nahi kiya
  -> inbox dekho, npm ka mail aaya hoga

"EPUBLISHCONFLICT / cannot publish over previous version"
  -> ye version pehle hi hai
  -> npm version patch  phir dobara publish

"Package name too similar to existing package"
  -> naam badlo. Backup naam (sab FREE hain):
       streamos-engine
       stream-os-subscription-engine

"ENEEDAUTH / unable to authenticate"
  -> npm login dobara karo

"404 PUT" (OIDC ke waqt)
  -> Node purana hai. Workflow mein node-version: "24.x"
  -> npm CLI >= 11.5.1 chahiye
