PART 3 — CONCEPT (ANATOMY — HADDI PASLI)
----------------------------------------------------------------

  POORA SYNTAX:

    const result = array.reduce(function (acc, cur, index, arr) {
      return NAYA_ACC;
    }, INITIAL_VALUE);

  CHAAR HISSE:

    ┌─────────────┬──────────────────────┬──────────────┐
    │ HISSA       │ MATLAB               │ KITNI BAAR   │
    ├─────────────┼──────────────────────┼──────────────┤
    │ acc         │ haath mein jo hai    │ har baar     │
    │ cur         │ aaj ka item          │ har baar     │
    │ index       │ kitne number pe hai  │ KAM HI CHAHIYE│
    │ arr         │ poora array          │ KAM HI CHAHIYE│
    │ INITIAL     │ register ka 0        │ EK BAAR      │
    └─────────────┴──────────────────────┴──────────────┘

  SABSE CHHOTA ROOP (90% yahi chalta hai):

    const result = array.reduce((acc, cur) => acc + cur, 0);
                                  │     │            │   │
                                  │     │            │   └─ INITIAL
                                  │     │            └───── JODO
                                  │     └────────────────── aaj ka item
                                  └──────────────────────── haath mein

  ⭐ SABSE ZAROORI RULE ⭐

       INITIAL VALUE HAMESHA DO.

    Kyun? Neeche PART 5 mein dikhata hoon —
    bina initial value ke code KHATARNAAK bug paida karta hai.

PART 5 — ⚠️ SABSE KHATARNAAK BUG (INITIAL VALUE)
----------------------------------------------------------------

  YE CODE DEKH:

    const total = [].reduce((acc, cur) => acc + cur);
    //              ^^ KHALI ARRAY
    //                          ^^ KOI INITIAL VALUE NAHI

    // 💥 TypeError: Reduce of empty array with no initial value

  KAB HOGA YE?
    - Bank se koi transaction nahi aaya
    - User ne koi plan nahi liya
    - API se empty list aayi

  AUR YE SAB ROZ HOTA HAI REAL LIFE MEIN.

  ISILIYE:

    ❌ [].reduce((a,b) => a + b)        -> CRASH
    ✅ [].reduce((a,b) => a + b, 0)     -> 0  (safe)

  EK AUR CHHUPA HUA FARAK:

    [5].reduce((a,b) => a + b)          -> 5
    (initial nahi to pehla item hi initial ban jata hai
     aur callback EK BAAR BHI NAHI chalta)

    [5].reduce((a,b) => a + b, 0)       -> 5
    (callback chalta hai: 0 + 5 = 5)

  NUMBER TO SAME DIKHA, PAR:
    ["5"].reduce((a,b) => Number(a) + Number(b))     -> "5"  (STRING!)
    ["5"].reduce((a,b) => Number(a) + Number(b), 0)  -> 5    (NUMBER) ✅

  YE BUG 3 GHANTE DEBUG KARWA SAKTA HAI.
  INITIAL VALUE KABHI MAT BHULNA. 🔒

    /**
     * Total paisa kharch hua — sirf valid amounts.
     * @param {Array<Array>} rows  [date, merchant, amount]
     * @returns {{status:number, ok:boolean, data?:number, error?:string}}
     */
    function getTotalSpend(rows) {
      // Guard clause 1 — array hai bhi ya nahi
      if (!Array.isArray(rows)) {
        return { status: 400, ok: false, error: "rows must be an array!" };
      }

      // Guard clause 2 — khali ho to jhootha data mat de
      if (rows.length === 0) {
        return { status: 200, ok: true, data: 0 };
      }

      const total = rows.reduce((acc, row) => {
        // Defensive: row array hai?
        if (!Array.isArray(row)) return acc;

        const amount = row[2];

        // Defensive: amount asli number hai?
        if (!Number.isFinite(amount)) return acc;

        // Negative = refund, spend nahi
        if (amount < 0) return acc;

        return acc + amount;
      }, 0);                              // ⭐ INITIAL VALUE

      return { status: 200, ok: true, data: total };
    }

  KYA SEEKHNE JAISE HAI:
    ✅ Guard clauses SABSE PEHLE
    ✅ Initial value HAMESHA
    ✅ Har item ko check karne se pehle use mat karo
    ✅ Consistent return: { status, ok, data | error }
    ✅ JSDoc upar
    ✅ Ek kaam, poora kaam

------------------------------------------------------------------
ASLI CODE (Redux ka, bilkul waisa ka waisa):
------------------------------------------------------------------
    export default function compose(...funcs) {
      if (funcs.length === 0) {
        return (arg) => arg
      }

      if (funcs.length === 1) {
        return funcs[0]
      }

      return funcs.reduce(
        (a, b) =>
          (...args) =>
            a(b(...args))
      )
    }

------------------------------------------------------------------
AB LINE BY LINE, AAM AADMI KI BHASHA MEIN:
------------------------------------------------------------------

  compose KYA KARTA HAI?
    3 function hain:  f, g, h
    compose(f, g, h)  banata hai EK function
    jo ulta chalta hai:  f( g( h(x) ) )

  SOCH: Factory ki assembly line.
    Kachcha maal -> h -> g -> f -> taiyaar samaan

  LINE 1:  if (funcs.length === 0) return (arg) => arg
    "Agar koi function hi nahi diya,
     to aisa function de do jo jo aaya wo wapas kar de."
    (Jaise: khali mixer -> jo dala wo nikal gaya)
    Ye GUARD CLAUSE hai. Bina iske reduce khali array pe CRASH.
    ⭐ DEKHA? Redux bhi wahi rule follow karta hai
       jo maine PART 5 mein sikhaya.

  LINE 2:  if (funcs.length === 1) return funcs[0]
    "Ek hi function hai to usko waise hi de do."
    Chhota optimization. Kam kaam = tez code.

  LINE 3:  funcs.reduce((a, b) => (...args) => a(b(...args)))
    ASLI JAADU. Chalo todte hain:

    reduce ka accumulator = EK FUNCTION
    (haan! reduce sirf number nahi, FUNCTION bhi bana sakta hai)

    Maan le funcs = [f, g, h]

    Round 1:  a = f,  b = g
              bana: (...args) => f(g(...args))
              haath mein ab:  "f ke andar g"

    Round 2:  a = (f∘g),  b = h
              bana: (...args) => (f∘g)(h(...args))
              matlab: f(g(h(...args)))
              haath mein ab:  "f ke andar g ke andar h"

    RESULT:  f(g(h(x)))   ✅

  DHYAN DE — KOI INITIAL VALUE NAHI!
    Kya Redux galti kar raha hai?

    NAHI. Kyunki:
      - funcs.length === 0 pehle hi handle ho gaya (LINE 1)
      - funcs.length === 1 pehle hi handle ho gaya (LINE 2)
      - Yahan tak aaya matlab 2+ functions PAKKA hain

    ⭐ YE HAI SENIOR SOCH:
      "Main initial value nahi de raha...
       kyunki maine pehle hi ensure kar liya hai
       ki array khali nahi hai."

    Tu abhi LINE 1-2 jaisa guard lagana seekh raha hai.
    Guard ho to initial value chhoot sakti hai.
    Guard NAHI to KABHI NAHI chhootni chahiye. 🔒

  HINGLISH MEIN EK LINE MEIN:
    "Reduce ne 3 alag function ko mila kar EK function
     bana diya. Bahut se -> ek. Bas yahi reduce hai."

  TUJHE KYA CHEEN KE RAKHNA CHAHIYE:
    1. Guard clauses pehle — industry standard hai, sirf
       mere rule nahi hain
    2. Reduce ka accumulator FUNCTION bhi ho sakta hai
    3. Khali input pehle handle karo, tabhi reduce bina
       initial value ke safe hota hai
