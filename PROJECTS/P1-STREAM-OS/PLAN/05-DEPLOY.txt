🤖 BONUS: AUTOMATIC PUBLISHING (EK BAAR SETUP, PHIR KABHI SOCHNA NAHI!)
==============================================================================

Maine tujhe 2 GitHub Actions bana ke diye hain:

File  |  Kya Karta Hai
.github/workflows/ci.yml  |  Har push par Node 18, 20, 22 par tests chalata hai → green ✅ badge
.github/workflows/publish.yml  |  Jab bhi tu GitHub Release banayega → automatically npm par publish ho jayega!

Setup (sirf ek baar):
~~~~~~~~~~~~~~~~~~~~~

1. npm par jao: https://www.npmjs.com/settings/~/tokens
2. Generate New Token → type: Automation
3. Token copy karo
4. GitHub repo → Settings → Secrets and variables → Actions → New repository secret
5. Name: NPM_TOKEN · Value: wo token
6. Add secret

Phir aage se har baar:
~~~~~~~~~~~~~~~~~~~~~~

      git add .
      git commit -m "fix: kya theek kiya"
      git push
      # Phir GitHub par Release banao → npm par khud publish ho jayega! 🤖
